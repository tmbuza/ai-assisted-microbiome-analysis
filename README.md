# AI-Assisted Microbiome Analysis

**Help me get from this dataset to an output I understand and can defend.**

A CDI Quarto book with three starting points:

- **Show me an example:** explore a finished report and how it was produced.
- **Help me prepare my data:** use templates and input checks.
- **Guide me through my analysis:** run, review, interpret, and export.

**Human → AI → Human:** the learner defines the question, AI assists the work, and the learner verifies and explains the result.

## Quick start

### 1. Open the project

Install R and Quarto. Open the repository folder in VS Code or your preferred editor. Run all commands from the repository root:

```bash
cd ai-assisted-microbiome-analysis
```

### 2. Set up the R environment

Start R from the repository root:

```bash
R
```

For a fresh project without `renv.lock`, run once:

```r
install.packages("renv", repos = "https://cloud.r-project.org")
renv::init(bare = TRUE)
renv::install(c("tidyverse", "vegan"), type = "binary")
```

If the repository already includes `renv.lock`, restore its recorded packages instead:

```r
# Install renv only if it is not available.
install.packages("renv", repos = "https://cloud.r-project.org")
renv::restore()
```

Exit R without saving the workspace:

```r
q(save = "no")
```

The repository uses one shared R environment for all examples. Commit `.Rprofile`, `renv.lock`, `renv/activate.R`, `renv/settings.json`, and `renv/.gitignore`. Keep the installed package library out of Git using the ignore rules generated by renv.

### 3. Check the inputs

```bash
Rscript scripts/R/01-check-inputs.R
```

Review `results/tables/input-checks.tsv`. Resolve failed checks before continuing.

### 4. Run the example

```bash
Rscript scripts/R/02-analyse-example.R
```

This script also validates the inputs. Outputs are saved in:

- `results/tables/`: sample totals, diversity, and feature proportions.
- `results/figures/`: composition and Shannon diversity figures.
- `results/session-info.txt`: R and package information.

### 5. Render and explore

```bash
quarto render
quarto preview
```

The rendered book is written to `docs/`. Code fences are non-executable; rendering does not run the analysis scripts.

### 6. Create your report

Copy the report template to the repository root:

```bash
cp templates/learner-report.qmd learner-report.qmd
```

Replace the prompts with your question, methods, observations, verification, and limitations. Then render:

```bash
quarto render learner-report.qmd --to html
```

Open the generated HTML report. Use **Print → Save as PDF** in your browser if needed.

## Project structure

| Location | Purpose |
|---|---|
| `_quarto.yml` | Shared book configuration and navigation |
| `index.qmd` | Domain opening page |
| `examples/community-comparison/` | First example’s learner chapters and finished report |
| `data/example/` | Synthetic counts, metadata, and taxonomy |
| `scripts/R/` | Input checks and analysis scripts |
| `results/` | Tables, figures, and decision log |
| `templates/` | Input, interpretation, and report templates |
| `renv.lock` and `renv/` | Shared R environment |
| `docs/` | Rendered book |

## Working conventions

- Run scripts and Quarto commands from the repository root.
- Keep one `_quarto.yml` and one renv environment for the domain.
- Add future examples under `examples/` and register their chapters in `_quarto.yml`.
- Use `../../results/figures/` for figure links in chapters inside `examples/community-comparison/`.
- Record decisions and verification in `results/decision-log.md`.
- After intentionally adding or updating R packages, run `renv::snapshot(packages = c("renv", "tidyverse", "vegan"))` and commit the updated lockfile.

## Example scope

The first example compares two groups using 24 synthetic samples and 15 fictional features. It demonstrates descriptive composition and diversity analysis, not biological inference or significance testing. It starts from a feature table rather than raw sequencing reads.

## Analyse your own tables

Keep the example intact. Put your three input files in `data/my-study/`, then run:

```bash
Rscript scripts/R/02-analyse-example.R data/my-study results/my-study
```

Use `templates/learner-report.qmd` for a blank report; `learner-report.qmd` at the root is the filled synthetic example. On systems without compatible binaries, omit `type = "binary"`; source installation may require compilers.

Included preview outputs were computed with Python; rerun the R scripts locally. The supplied lockfile is preserved unchanged. No new R dependencies were added.

## Taxon-comparison example

Nine chapters in `examples/taxon-comparison/` scaffold the question “Which taxa differ between groups, and how strong is the evidence?” They include an AI-assisted workflow diagram, analysis decisions, verification checkpoints, and a report scaffold. Navigation is included in `_quarto.yml` and `index.qmd`.

This example is in development: its dedicated synthetic dataset, R scripts, numerical findings, and figures are not included yet. ANCOM-BC2 is a candidate to validate, not an installed or tested dependency. The community-comparison workflow and `renv.lock` are unchanged.
