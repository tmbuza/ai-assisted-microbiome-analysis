Run the workflow

Complete workspace setup once. Then choose one dataset below and run its command from the repository root.

What the scripts do

Script in scripts/R/ Role
01-check-inputs.R Checks the three input tables; called automatically by the analysis
02-analyse-example.R Main entry point; checks inputs and generates figures and tables
05-verify-sample.R Optional independent check of one sample

The main script also compares its direct Shannon calculation with vegan for every sample. You do not need to run the checking script separately.

Dataset Input folder Output folder
Synthetic practice data/example/ results/example/
DietSwap data/dietswap/ results/dietswap/
Mouse59 data/mouse59/ results/mouse59/
Your own study data/my-study/ results/my-study/

Practice

Rscript scripts/R/02-analyse-example.R data/example results/example

Return to the practice outputs.

DietSwap

Rscript scripts/R/02-analyse-example.R data/dietswap results/dietswap

Return to the DietSwap outputs.

Mouse59

Rscript scripts/R/02-analyse-example.R data/mouse59 results/mouse59

Return to the Mouse59 outputs.

Your own study

Place your three tidy TSV files in data/my-study/ before running:

Rscript scripts/R/02-analyse-example.R data/my-study results/my-study

Return to the checklist for your own study.

After an error

Stop and resolve the error before reading results. Files from an earlier run may still be present. A successful run should finish without an error and produce the outputs for the dataset you selected.

Find the outputs

Output within the selected results folder Use it to check
tables/alpha-diversity.tsv Count total, observed features, and Shannon for each sample
tables/relative-abundance.tsv Individual feature proportions
tables/composition-display.tsv The eight displayed features and pooled Other
tables/group-summary.tsv Group summaries
figures/ Composition, Shannon diversity, and count-total plots
session-info.txt R and package versions

Rerunning the same command writes to the same output folder. Choose a separate output folder when exploring filtering or other changes you want to compare with the original run.

Optional: independently verify one sample

For the synthetic practice:

Rscript scripts/R/05-verify-sample.R data/example results/example A01

For another dataset, replace both folder paths and the sample ID. Reference IDs and expected values appear on each example’s explanation page. All three rows should show TRUE under agrees.

This exercise helps you understand the calculation. It is optional for completing the workflow; checking your descriptions against the saved tables remains part of every analysis.
